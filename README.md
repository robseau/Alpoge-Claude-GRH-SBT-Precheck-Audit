# Alpoge-Claude-GRH-SBT-Precheck-Audit
Independent preliminary audit of the Alpöge–Claude GRH argument using revised Spectral Barrier criteria, native rigidity, information sufficiency, and Lean verification.

**Research status: Preliminary investigation — no verdict on the GRH proof.**

This repository develops and applies a restricted mathematical certification framework to selected interfaces of the Alpöge–Claude GRH argument.

The investigation is independent and does not presume either correctness or failure of the proof. Results are classified as PASS, FAIL, or OPEN only within explicitly stated scopes.

A successful preliminary audit does not constitute independent certification of the entire GRH proof. A possible defect is not classified as a proof failure without identifying the exact mathematical obstruction and its role in the argument.

The N1 spectral framework is presented as a separate mathematical example of the distinction between constructing a spectral object and certifying its visibility.
